# Super Fitness – Modern Fitness Website

Super Fitness is a full-featured fitness website created from the official Figma design. It focuses on delivering a clean, modern, and high-energy user experience for gym brands and personal fitness businesses.

The website includes:
- Custom hero section
- Program highlights
- Trainer profiles
- Class schedule layouts
- Membership pricing tables
- Testimonials and success stories
- Dynamic contact/join section

Built with reusable UI components, a scalable folder structure, and fully responsive breakpoints to ensure great performance across mobile, tablet, and desktop devices.  
Perfect as a starting point for commercial fitness websites or design-to-code projects.
